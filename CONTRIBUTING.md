# Contributing to mysterymaps

## Before you write a function, look for it

This ecosystem has been bitten repeatedly by the same failure: the same helper
written twice, load order deciding which one runs, and a fix applied to one copy
being a fix applied to none. The failures are silent — no error, plausible
output.

A cross-repo function index exists. Search it first:

```bash
awk -F'\t' 'tolower($1) ~ /jenks|legend|credential/ {printf "%-40s %s\n", $1, $2}' \
  ~/muffly-refs/FUNCTION_INDEX.tsv
```

Canonical homes:

| Package | Owns |
|---|---|
| `mufflyaccess` | constants and safe arithmetic: bands, CONUS geography, `safe_rate()` |
| `twostep` | E2SFCA accessibility, population-weighted coverage, access-language guard |
| `mysterymaps` | map construction |
| `isochrones` | routing, water masks, the isochrone pipeline |
| `cliff` | workforce retirement modelling |

**If the capability genuinely does not exist, add it to the package that should
own it.** Do not keep a private copy and document why your caller is special —
that argument is the one against every library improvement ever made.

## Style

* Exported functions are `mysterymaps_*`. Keep them free of any one study:
  a function that mentions midwives belongs in the study, not here.
* Document *why*, not what. A comment that says what the next line does is
  noise; a comment that says which bug the line prevents is the reason anyone
  keeps it.
* Guards error rather than filter. Silently dropping rows moves a denominator
  without anyone noticing.
* Mapping packages are Suggests. Guard with `requireNamespace()`.

## Before opening a PR

```r
devtools::document()   # NAMESPACE is generated — never hand-edit
devtools::test()
devtools::check()
Rscript data-raw/make_readme_figures.R   # if you changed map output
```

`devtools::check()` builds a PDF manual, so it needs LaTeX. BasicTeX is enough
but ships without `inconsolata`, which `Rd2pdf` loads by default; without it the
check fails at `checking PDF version of manual` with a LaTeX error that says
nothing about fonts. Install it into your own tree, no `sudo` required:

```sh
tlmgr init-usertree
tlmgr --usermode install inconsolata
```

`pdflatex` lives in `/Library/TeX/texbin` on macOS, which a fresh non-login
shell does not have on `PATH` — `eval "$(/usr/libexec/path_helper)"` if the
check claims LaTeX is missing when it plainly is not.

`NAMESPACE` has twice silently stopped being roxygen-managed in this repo, once
from a stray blank line above the `# Generated by roxygen2` marker and once from
a rebase conflict resolved by side-picking. Both times roxygen printed
`Skipping NAMESPACE`, kept writing man pages, and `R CMD INSTALL` reported
`DONE` with stale exports. If an export appears to vanish, check line 1 of
`NAMESPACE` first, and regenerate generated files after a conflict rather than
merging them by hand.

## Reporting a bug

Include the map, or the code that builds it, and what you expected to see.
Cartographic bugs are usually visible and rarely throw.
