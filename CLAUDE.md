# mysterymaps

An R package of map-construction functions for healthcare access and
mystery-caller studies: county choropleths, dissolved drive-time coverage
surfaces, provider dot maps, and the legend/label/notes furniture they need.
`mysterymaps_county_access_map()` assembles the common case from pieces that are
also exported individually.

**Read `CONTRIBUTING.md` before changing anything.** It carries the rules below
and the bugs that produced them. The short version:

## Before writing a helper, look for it

This ecosystem has repeatedly grown the same function twice, with load order
deciding which one runs and a fix to one copy fixing neither. Search the
cross-repo index first (`~/muffly-refs/FUNCTION_INDEX.tsv`), and add genuinely
new capability to the package that should own it — `mufflyaccess` for constants
and safe arithmetic, `twostep` for accessibility, `isochrones` for routing and
water masks, `mysterymaps` for map construction.

## Conventions

- Exported functions are `mysterymaps_*` and carry no single study's specifics.
- Comment *why*, not what — which bug a line prevents is why it survives review.
- Guards error; they do not silently filter. Dropping rows moves a denominator
  invisibly.
- Mapping packages are Suggests, guarded with `requireNamespace()`.
- Roxygen with markdown. `@param` types go in backticks — `` `character(1)` ``,
  never `[character(1)]`, which roxygen renders as a link to a topic that does
  not exist and `R CMD check` flags.
- Keep Rd prose ASCII. Em dashes and `²` survive the build but trip the HTML
  manual validator.

## NAMESPACE is generated — never hand-edit

It has twice silently stopped being roxygen-managed here (a stray blank line
above the `# Generated by roxygen2` marker; a rebase resolved by side-picking).
Both times roxygen printed `Skipping NAMESPACE`, kept writing man pages, and
install reported `DONE` with stale exports. If an export seems to vanish, check
line 1 of `NAMESPACE` first.

## Checks

```r
devtools::document()
devtools::test()
devtools::check()
Rscript data-raw/make_readme_figures.R   # if map output changed
```

`ggmap` and `hereR` are Suggests that may not be installed; use
`_R_CHECK_FORCE_SUGGESTS_=false` to check without them. The `mysterycall`
dependency is GitHub-only (see `Remotes:`), so `R CMD check --as-cran` warns
about it by design — the package is not currently CRAN-bound.
