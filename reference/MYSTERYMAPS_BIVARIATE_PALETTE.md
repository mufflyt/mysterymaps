# Default bivariate choropleth palette (3x3 classes)

Teal/magenta/blue palette (after Joshua Stevens' widely-used bivariate
scheme) for
[`mysterymaps_bivariate_choropleth_map()`](https://mufflyt.github.io/mysterymaps/reference/mysterymaps_bivariate_choropleth_map.md).
Keys are `"<x_class>-<y_class>"`, each `1` (low) to `3` (high).

## Usage

``` r
MYSTERYMAPS_BIVARIATE_PALETTE
```

## Format

A named character vector of 9 hex colours.
